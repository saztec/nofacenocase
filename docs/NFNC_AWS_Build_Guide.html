CLTrain a custom model — Rekognition Custom Labels

Train your own model that locates a person in a bed photo — bounding box, not just a whole-image label — then wire it into the bed check. A genuinely trained model (your labelled data → an AWS training job → accuracy metrics → real pixel coordinates back at inference), all inside AWS. It sits alongside the built-in emotion analysis, not instead of it.

Cost & time — read first. Training is a small one-off (billed per training-hour; a tiny dataset trains in well under an hour). The running model is billed per inference-hour (~a few $/hr) and only works while "Started". You must STOP the model after every test/demo or it quietly runs a bill. Start → test → stop, and the whole thing costs a few single dollars.

Gather the dataset

Two folders of images:

  1. occupied/ — a bed with a person in it. Aim for ~15–20 images.
  2. empty/ — the same bed made up and empty. Aim for ~15–20 images.

Vary angle, distance, lighting and blanket arrangement so it learns "person present", not one exact pose. Phone photos of a real bed with a consenting volunteer are the cleanest source — your own data, no licensing or privacy issues, and honest to explain in the viva.

Keep both classes on similar backgrounds so the model learns occupancy, not "this room = occupied".

Create the project & dataset — bounding boxes, not whole-image tags

This trains an object detector: instead of tagging each photo occupied/empty, you draw a box around the person in each occupied photo. Rekognition's labeling tool captures the pixel coordinates itself when you drag the box — you never type or compute a coordinate by hand, in training or at inference time.

  1. Console → Rekognition → left sidebar Custom Labels. If prompted, let it create the Custom Labels S3 bucket (accept the default).
  2. Projects → Create project → name nfnc-bed-occupancy → Create.
  3. Datasets → Create dataset → Start with a single dataset (it auto-splits a test set at training time).
  4. Upload images from your computer → upload all occupied/ and empty/ images.
  5. Add one label: occupant.
  6. Open each occupied photo → select the occupant label → switch the tool to bounding box → drag a rectangle around the person → save. Repeat for every occupied photo.
  7. Leave every empty photo completely unlabeled — no box, no tag. These are your negative examples; they teach the model what "nobody here" looks like.
This beats two whole-image labels because the model learns to actually find a person-shaped region, not guess from lighting or background. It also means inference hands back the exact pixel-ratio box it detected — real coordinates from the trained model, drawn live over your captured photo in the app.

  3. When done, open the model → Evaluation results. Screenshot the F1 score, precision and recall — gold for the report's development-process section.
